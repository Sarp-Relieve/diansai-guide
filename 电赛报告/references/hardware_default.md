## 3. 总框图模块名推荐（小车默认）

```
车载电池与电源转换
    ├─ 供电 → 汇电籽-601（ICM42688，UART）── 航向角反馈 ────────┐
    ├─ 供电 → 敢为八路灰度（串行/并口）── 横向偏差反馈 ──────────┤
    ├─ 供电 → 核心主控 地猛星 MSPM0G3507 ── 触发 → 声光（BEEP+LED）│
    ├─ （可选）泰山派视觉 ── UART 目标/偏差 ────────────────────┤
    └─ 供电 → TB6612（或 AT8236）── 驱动 → 左右 310（或 513）+编码器
                      ↑ PWM 调速与差速控制
```

## 4. 方案二表述示例片段（可改写，勿当终稿）

**驱动（310 车）：**  
方案二：采用 TB6612 配合 310 带编码器直流减速电机（额定约 7.4V）。相对 L298N，该驱动导通损耗与发热更小，更适配车载 7.4V 与小车体积约束；在峰值电流约 1.2A 量级下与 310 堵转电流相匹配，PWM 差速平滑，编码器可接入速度/里程闭环。

**驱动（513 车，若用户采用）：**  
方案二：采用 AT8236 等高电流驱动配合 513 电机（约 12V）。其峰值电流能力约 6A，可为堵转约 3.2A 的大扭矩电机提供裕量，并可通过排母兼容原 TB6612 接口布局。

**IMU：**  
方案二：采用汇电籽-601 模块（ICM42688，UART 输出姿态）。相对仅依赖编码器的航迹推算或 I2C 六轴方案，Z 轴航向可直接参与闭环矫正，在无黑线盲走段抑制偏航累积。

**灰度：**  
方案二：采用敢为八路灰度传感器（经辅助板串行输出以节省主控 IO，或 GPIO 并口）。在赛题不得安装摄像头的前提下，八路信息经加权/分级映射为连续横向偏差 e(k)，为位置式 PD/PID 提供误差反馈，契合投影不得脱离引导线的苛刻判据。

**视觉（题需要时）：**  
方案二：采用泰山派运行 OpenCV 或 YOLO，将目标位置/偏差经 UART 回传 MSPM0G；主控专注实时运动控制，避免在 MCU 内处理原始图像导致周期抖动。
