# 行文逻辑精读（从示例报告抽象）

> 目的：把示例 Word 截图里的**语言节奏**固化成可迁移规则。  
> 示例原题是 MSPM0 自动行驶小车；你写别的题时只借节奏，不借零件与数据。

---

## 1. 引言段的信息密度

示例引言两段：

**第一段 = 难포인트射**  
- 开场 1 句领域  
- 1 句本题  
- 随后用长句串联：小半径圆弧、投影限制、动态响应、闭环精度、离心力与惯性、无摄像头、灰度布局、跨赛段调度、全局坐标与状态机、节点声光、模式无缝切换  

特点：难点是**并列约束清单**，不是故事。每个难点都能在后文方案或理论里找到落点。

**第二段 = 对策收口**  
「为了克服上述难题，本系统采用了【线性灰度阵列、PID、万向轮】，通过严格的方案论证和参数整定，实现了…平滑循迹与精准启停。」

迁移：把括号里的三件套换成你的三件套即可。

---

## 2. 方案比较的「镜像结构」

示例每个模块都是：

```
方案一：【传统/廉价/初学者方案】
  - 能力边界写清楚
  - 用本题某一硬约束打死它（算力不够 / 转弯半径大 / 高速扭矩跌 / 只能输出开关量…）

方案二：【最终方案】
  - 不写广告词，写「如何扣题」
  - 尽量出现题面关键词（投影脱离圆弧即失败、用时越少越好、不得安装摄像头…）

综合比较：为【再次点题约束】，本系统选择方案二。
```

注意示例**不会**写方案三，也不会在比较里贴参数表——干净利落。

反面方案要「像真的会有人选」，不要写稻草人。

---

## 3. 理论节的「公式—释义—工程化—回题」

示例 §3.1：

1. 宣布：位置式离散 PID，差速  
2. 公式 (1)  
3. 符号逐一中文定义（u(k)、e(k)、Kp/Ki/Kd）  
4. e(k) 的传感器来源：7 路加权，离中心越远权重越大 → 离散变连续  
5. 工程化：高速去积分 Ki=0，靠 PD；P 回复、D 阻尼  
6. 回题：抑制 40cm 入弯超调与震荡，投影不离线  

迁移检查表：

- 有没有编号公式？  
- 有没有符号说明？  
- 有没有传感器→误差的桥？  
- 有没有「我们实际砍掉/保留了哪一项」？  
- 最后有没有扣回题面失败判据？

## 4. 问题—对策节的最短闭环

示例 §3.2 只有一条，但结构完整：

| 元件 | 示例原文角色 |
|------|----------------|
| 场景 | 要求(3) A→C 对角线无黑线盲走 |
| 失效 | 仅编码器推算 → 跑偏撞不上 C 点黑线 |
| 增量 | 引入 MPU6050 Z 轴航向 |
| 融合 | 与编码器多传感器融合 |
| 效果 | 航向闭环矫正，盲走直线度提高 |

写多条问题时，**每条都保持五件套**，不要写成流水账日记。

---

## 5. 测试节的「可复现」语气

示例 §4 不吹成绩，先写：

- 用什么尺子/表  
- 车怎么摆、怎么启动  
- 看什么现象算成功/失败  
- 怎样处理偶然误差（3 次平均）  

然后再留 §4.4 结果位。  
迁移：即使发挥题很炫，测试方法也要让评委觉得**别人按你的方法能复测**。

---

## 6. 结论的情绪曲线

```
5.1 高昂完成（主控+能力+基础成绩+发挥成绩+平稳+声光+圆满）
5.2 冷静缺陷（达标前提下暴露极限问题 → 根因工程分析）
5.3 成长与两条路（融合体悟 + 未来控制升级 + 未来电源/结构升级）
```

示例 5.2 根因写的是：**电池压降 → 同 PWM 下力矩下降**，并上升到「仅位置式 PD、无动态电压补偿」。  
这是「现象→机理→方法缺陷」三层，不要只写「有时候不稳」。

5.3 示例两条展望：

1. 更高级串级 PID 或模糊 PID → 非线性工况动态响应  
2. 专用稳压与动态监控 → 隔绝电池波动对转速干扰  

迁移：两条分别落在**算法**与**电源/结构/传感**为佳，避免两条都虚。

## 7. 用词白名单 / 灰名单

**常用且得体：**

克服、严格、论证、整定、契合、闭环、融合、抑制、量化、平滑、精准、严谨、圆满、暴露、隔绝

**慎用：**

完美、绝对、革命性、赋能、闭环生态、打造、赋能级、SOTA

**示例喜欢的连接：**

- 「在…前提下」  
- 「从而将…转化为…」  
- 「经反复调参论证」  
- 「大大提高了…」  
- 「尽管…但在…我们发现…」  
- 「经工程分析，主要原因在于…」

---

## 8. 段落长度

- 方案一 / 方案二：各 2～4 句  
- 综合比较：1～2 句  
- 理论释义：公式后 1 段符号 + 1 段传感器 + 1 段工程化  
- 问题对策：2～4 句一条  
- 结论 5.1：1 大段；5.2：1～2 段；5.3：2 段  

整体偏「密」，少空行抒情，适配 8 页上限。
