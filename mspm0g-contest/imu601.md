# 汇电籽-601（默认 IMU）

> **地猛星小车默认姿态传感器 = 汇电籽-601**（ICM42688 + 板载 TI M0，UART）  
> **不是** MPU6050，**不是** 正点原子旧 ATKP（`55 55`）协议。  
> 资料：`汇电籽-601通信协议说明书.pdf`（2026.06.22）+ `汇电籽-601模块简要说明.pdf` + 官方例程 `car_06_imu601_read`

---

## 1. 模块规格

| 项目 | 值 |
|------|-----|
| 名称 | 汇电籽-601 |
| 传感器 | ICM42688 六轴 |
| 板载 MCU | TI M0（模块自解算姿态） |
| 接口 | **UART**（不是 I2C） |
| 波特率 | **115200** 8N1 无校验 |
| 字节序 | **小端** Little-Endian |
| 默认设备 ID | **0x60**（0xFF=广播，不可作 ID） |
| 上报频率 | 约 100Hz（模块侧） |
| 逻辑电平 | 高 3.3V / 低 0V |
| 供电 | **4.5~5.5V**，接 **5V**（V 脚） |
| 尺寸 | 约 31×28 mm（手册标注） |

### 接线（地猛星官方例程）

| 汇电籽-601 丝印 | 含义 | 地猛星 |
|----------------|------|--------|
| **V** | 5V | **5V** |
| **G** | GND | **GND**（必须共地） |
| **T** | 模块串口 TX | **PA25** = UART3_RX |
| **R** | 模块串口 RX | **PA26** = UART3_TX |

```
汇电籽-601.T (TX) ──► MSPM0G PA25 (UART3_RX)
汇电籽-601.R (RX) ◄── MSPM0G PA26 (UART3_TX)
汇电籽-601.V ──────── 5V
汇电籽-601.G ──────── GND
```

⚠️ 交叉接：模块 T→MCU RX，模块 R←MCU TX。  
⚠️ 供电用 **5V**，不要只接 3.3V（手册供电范围 4.5~5.5V）。

SysConfig：
```
ADD → UART → Name: IMU601 → Peripheral: UART3
  TX Pin: PA26
  RX Pin: PA25
  Baud: 115200, 8N1
  RX interrupt: enable
```

## 2. 统一帧格式

所有上下行帧：

| 字段 | 帧头1 | 帧头2 | 设备ID | 指令码 CMD | 长度 LEN | 数据 DATA | 校验 CS |
|------|-------|-------|--------|------------|----------|-----------|---------|
| 字节 | 1 | 1 | 1 | 1 | 1 | N | 1 |
| 值 | **0xAA** | **0x55** | **0x60** | 见下表 | N | 见下表 | 见下 |

**校验和：**
```
CS = (DevID + CMD + LEN + DATA各字节之和) & 0xFF
```
计算范围从 DevID 到 DATA 末字节，**不含** 帧头 AA 55，**不含** CS 自身。

## 3. 姿态角换算

协议中姿态角为放大 **100** 倍的整数，接收后 `/100.0f`：

| 角 | 类型 | 原始范围 | 真实角度 |
|----|------|----------|----------|
| **Pitch** | int16 | ±18000 | -180.00° ~ +180.00° |
| **Roll** | int16 | ±18000 | -180.00° ~ +180.00° |
| **Yaw** | **uint16** | 0~36000 | **0.00° ~ 360.00°** |

```c
angle_deg = raw / 100.0f;
```

---

## 4. 数据上报 CMD = 0x01

启动上报后，模块主动发 `CMD=0x01`。

### 模式 0：全数据（LEN = 18）

DATA = `[AccX, AccY, AccZ, GyroX, GyroY, GyroZ, Pitch, Roll, Yaw]`  
前 6 个：int16 原始；后 3 个：姿态角（×100，小端）。

### 模式 1：仅姿态（LEN = 6）——例程默认解析此模式

DATA = **`[Yaw, Pitch, Roll]`**（注意：**Yaw 在前**）

整帧 12 字节示例结构：
```
AA 55 60 01 06  |  YawL YawH  PitchL PitchH  RollL RollH  |  CS
```

官方例程注释样例：
```
AA 55 60 01 06 E0 8C 18 04 2C F7 36
```

## 5. 控制指令（MCU → 模块）

设备 ID 均用默认 `0x60`。

| CMD | 名称 | LEN | DATA | 完整示例 (HEX) |
|-----|------|-----|------|----------------|
| **0x0A** | 启动/停止上报 | 1 | `01`=启动，`00`=停止 | 启动 `AA 55 60 0A 01 01 6C` |
| **0x0B** | 设置输出模式 | 1 | `00`=全数据，`01`=仅姿态 | 仅姿态 `AA 55 60 0B 01 01 6D` |
| **0x10** | 触发重新校准 | 0 | 无 | `AA 55 60 10 00 70` |
| **0x12** | 软复位 MCU | 0 | 无 | `AA 55 60 12 00 72` |
| **0x14** | Yaw 单圈比例校准 | 4 | float32 实测角度（小端） | 写 360.0：`AA 55 60 14 04 00 00 B4 43 6F` |

### ACK：CMD = 0xF0

模块应答控制指令：
- DATA[0] = 被应答的原 CMD
- 后续字节为附加状态

示例：`AA 55 60 F0 01 0A 5B` → 成功执行了 `0x0A`。

### 常用指令速查

```
启动上报：     AA 55 60 0A 01 01 6C
停止上报：     AA 55 60 0A 01 00 6B
全数据模式：   AA 55 60 0B 01 00 6C
仅姿态模式：   AA 55 60 0B 01 01 6D
重新校准：     AA 55 60 10 00 70
软复位：       AA 55 60 12 00 72
```

## 6. 推荐初始化流程（对齐官方 car_06）

```c
/* 1) 软复位 */
static const uint8_t cmd_reset[] = {0xAA, 0x55, 0x60, 0x12, 0x00, 0x72};
uart_send(IMU601_INST, cmd_reset, sizeof(cmd_reset));
delay_ms(300);

/* 2) 可选：Yaw 比例校准 0x14（参数按实车微调，官方例程有一组标定值） */
/* 3) 设为仅姿态模式（省带宽，例程默认解析 LEN=6） */
static const uint8_t cmd_mode_att[] = {0xAA, 0x55, 0x60, 0x0B, 0x01, 0x01, 0x6D};
uart_send(IMU601_INST, cmd_mode_att, sizeof(cmd_mode_att));
delay_ms(50);

/* 4) 启动上报 */
static const uint8_t cmd_start[] = {0xAA, 0x55, 0x60, 0x0A, 0x01, 0x01, 0x6C};
uart_send(IMU601_INST, cmd_start, sizeof(cmd_start));

/* 5) 使能 UART RX 中断 */
NVIC_EnableIRQ(IMU601_INST_INT_IRQN);
```

静止校零：发 `0x10` 重新校准，或记录当前 yaw 作零偏 `yaw0`，之后用 `wrap(yaw - yaw0)`。

## 7. 接收解析模板（仅姿态模式）

```c
typedef struct {
    float yaw;    /* 0 ~ 360 deg */
    float pitch;  /* -180 ~ 180 */
    float roll;
} Attitude_t;

/* 校验：从 buffer[2]=DevID 到 buffer[10]=DATA末 */
static uint8_t imu_checksum_ok(const uint8_t *f, uint8_t total_len)
{
    /* total_len = 12 for attitude-only frame */
    uint8_t cs = 0;
    for (uint8_t i = 2; i < total_len - 1; i++) cs = (uint8_t)(cs + f[i]);
    return cs == f[total_len - 1];
}

static void parse_attitude_only(const uint8_t *payload /* 6 bytes */, Attitude_t *o)
{
    uint16_t yaw_u   = (uint16_t)(payload[0] | (payload[1] << 8));
    int16_t  pitch_s = (int16_t)(payload[2] | (payload[3] << 8));
    int16_t  roll_s  = (int16_t)(payload[4] | (payload[5] << 8));
    o->yaw   = yaw_u   / 100.0f;
    o->pitch = pitch_s / 100.0f;
    o->roll  = roll_s  / 100.0f;
}

/* ISR：只收字节；组帧可在 ISR 轻量完成或丢环形缓冲主循环解析 */
/* 帧同步：见到 AA 55 后收 DevID/CMD/LEN/DATA/CS */
```

**铁律：**
- ISR 里禁止重计算 / printf / OLED；最多入环缓或轻量组帧
- 主循环读 `current_attitude` 做显示/控制
- Yaw 为 **0~360**；做差速/转向 PID 前先 `wrap` 到 ±180：
```c
static float wrap180(float a) {
    while (a >  180.f) a -= 360.f;
    while (a < -180.f) a += 360.f;
    return a;
}
float err = wrap180(target - yaw);
```

## 8. 全数据模式解析要点（CMD=0x01, LEN=18）

DATA 共 18 字节，小端 int16×9：

| 偏移 | 字段 | 类型 |
|------|------|------|
| 0 | AccX | int16 |
| 2 | AccY | int16 |
| 4 | AccZ | int16 |
| 6 | GyroX | int16 |
| 8 | GyroY | int16 |
| 10 | GyroZ | int16 |
| 12 | Pitch | int16 ×100 |
| 14 | Roll | int16 ×100 |
| 16 | Yaw | uint16 ×100（按手册姿态规则） |

转向阻尼可用 GyroZ；原始 gyro 比例以模块手册/实测标定为准。

## 9. 与控制结合（Yaw PID 转向）

1. 静止发 `0x10` 或记录 `yaw0`
2. 目标：`target = wrap360(yaw0 + 90)` 或用 ±180 误差
3. `err = wrap180(target - yaw)`（若用 0~360 先统一）
4. `out = Kp*err + Ki*i - Kd*gyroZ`（全数据模式才有可靠 gyroZ）
5. 左右轮差速：`left=+pwm, right=-pwm` 原地转；方向反了反号
6. 停稳：`|err|<3°` 且 `|gyroZ|` 小并连续 N 拍
7. **先抬轮测试**

完整例程见 `examples/imu601_yaw_pid_90deg_turn.md`。

## 10. 禁止事项 / 常见错误

| 错误 | 正确 |
|------|------|
| 当 I2C/MPU6050 用 | **UART 115200** |
| 帧头写成 `55 55`（旧 ATKP） | 帧头 **`AA 55`** |
| Yaw 当 int16 有符号 0 中心 | Yaw 是 **uint16，0~360** |
| 仅姿态模式按 Pitch,Roll,Yaw 顺序解析 | 顺序是 **Yaw, Pitch, Roll** |
| 模块 V 接 3.3V | V 接 **5V** |
| T/R 不交叉 | T→MCU RX，R←MCU TX |
| 校验含帧头 | CS **从 DevID 起算** |
| 与云台 KEY3/4 抢 PA25/PA26 | 小车占 IMU 时按键改脚 |

## 11. 与 24H_4

- UART3 脚与 24H_4 一致（PA25/PA26）
- 调试口另用 UART0 **PA10/PA11**
- 24H_4 初始化默认只 `0x12` 软复位后开中断

## 12. MPU6050 关系

- **默认 IMU = 汇电籽-601**
- MPU6050 仅作备选 I2C 方案，见 `i2c.md`；用户明确说“用 6050”时才用
- 接线图里 PA0/PA1 的 MPU6050 位：默认工程可不接；脚可留作他用或备用
