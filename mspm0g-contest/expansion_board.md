# 地猛星小车拓展板 + 多开关按键板

> 资料来源：用户提供的拓展板 / 按键板原理图 PDF（嘉立创 EDA）  
> 配合：立创·地猛星 MSPM0G3507 排针直插  
> **本文件取代旧 skill 里含糊的“25E 拓展板”描述**

---

## 一、拓展板是什么

一块插在地猛星上的底板/扩展板，板上固定或引出：

| 区位 | 器件/接口 |
|------|-----------|
| OLED 座 | 0.96" I2C OLED（GND/3V3/SCL/SDA） |
| TB6612 座 | 电机驱动模块座 + 电机输出 |
| 地猛星排母 | 左右 20P，对应地猛星全部信号脚 |
| 编码器座 U8/U9 | 左/右轮编码器 6P（XH2.54） |
| 电源座 U5/U6/U7 | GND/5V/3V3/VM 等 |
| UART0 / UART3 座 | printf / 汇电籽-601 |
| 舵机座 H3 | GND/5V/PA27 |
| 灰度/扩展 H2 | 7P：GND/5V/PA17/PB8/PB9/PA24/PA2 |
| TVS | SMF6.0CA 在 5V 上 |

**重要：软件配置以 24H_4 empty.syscfg 为准（ref_24h4.md）。**

### 2.8 地猛星排针透传（U1~U4）

拓展板 20P 排母顺序与地猛星一致，例如一侧：

`PA0, PA1, PA28, PA31, NRST, PA2, PB24, PB20, PB19, PB18, PA7, PB2, PB3, PA8, PA9, PB6, PB7, 5V, GND, …`

未在专用座上的脚（如 **PB6/PB7 按键、PA16 旋钮 ADC、PA0/PA1 备用 I2C**）仍从排针/杜邦引出。

## 三、多开关按键板（10 键 + 旋钮）

### 3.1 板载器件

| 位号 | 型号/规格 | 数量 | 说明 |
|------|-----------|------|------|
| SW1~SW10 | KH-6×6×5H-STM | 10 | 轻触按键 |
| R1 | RK097 10kΩ 电位器 | 1 | 旋钮（ADC） |
| H1 | 2.54 10P 直插 | 1 | **SW1~SW10 信号出线** |
| H2 | 2.54 2P | 1 | 公共端/电源相关 |
| H3 | 2.54 3P | 1 | 电位器 3 线（GND / 滑臂 / Vref） |

布局（正面）：SW1→SW10 从左到右一排，上方 H1 10P，侧方旋钮。

### 3.2 电气特性（与 KEY_ADC 例程一致）

- 按键：**按下为高** 的接法（例程 `PULL_DOWN` + 上升沿）  
- 读取：`DL_GPIO_readPins` 非 0 = 按下  
- 旋钮：ADC 滑臂 → **PA16**（例程名 `xuanniu`，ADC1 CH1，内部 2.5V VREF）

### 3.3 与地猛星/拓展板的推荐连接

按键板 **不焊死在拓展板上**，用杜邦从 H1/H3 接到地猛星排针（或拓展板透传脚）。

**官方 KEY_ADC / 小车例程已验证：**

| 按键板 | 地猛星 | 例程名 | 说明 |
|--------|--------|--------|------|
| **KEY1** | **PB6** | 24H_4 切 task |
| **KEY2** | **PB7** | 24H_4 启动 |
| **旋钮滑臂 (H3)** | **PA16** | xuanniu ADC | 10k 电位器 |
| 旋钮两端 | GND / 3V3 或 2.5V 参考 | | 与 ADC 量程一致 |
| 按键公共端 | 按 PCB：接 3V3（上拉供电）或按实际原理 | | 与 PULL_DOWN 匹配 |

**H1 针序与 SW 号：**  
PCB 丝印 SW1…SW10 从左到右；H1 为 10 路独立信号。  
**除 SW9/SW10 外，SW1~SW8 对应接到哪几个 MCU 脚由用户杜邦决定**——生成代码前必须问：

> “按键板 H1 的 SW1~SW8 分别接到地猛星哪些脚？SW9/SW10 是否仍是 PB6/PB7？旋钮是否 PA16？”

云台接线图曾用：KEY1=PB6，KEY2=PB7，KEY3=PA26，KEY4=PA25，KEY10=PB3——**与小车汇电籽-601 占用 PA25/PA26 冲突**，小车工程不要默认把 KEY3/4 派到 PA25/26。

### 3.4 SysConfig 模板（SW9/SW10 + 旋钮）

```
GPIO KEY:
  KEY1  PB6  Input  Pull-down  Interrupt Rising
  KEY2  PB7  Input  Pull-down  Interrupt Rising
ADC:
  Name xuanniu  Pin PA16  VREF 2.5V internal
```

```c
/* 按下=1 */
uint8_t key1 = (DL_GPIO_readPins(GPIOB, DL_GPIO_PIN_6) != 0);
uint8_t key2 = (DL_GPIO_readPins(GPIOB, DL_GPIO_PIN_7) != 0);
```

## 五、与旧 skill 差异

| 项目 | 旧 | 现（本拓展板） |
|------|----|----------------|
| A/B 与左右 | 每次只问、不写死 | 软件跟 24H_4 motor_id=1/2；左右以实车标定 |
| 编码器 | 多种旧表 | **右 PA21/22，左 PB19/20** |
| 按键 | PA25/PA26 等 | 小车默认 **PB6/PB7**；10 键其余脚问用户 |
| 旋钮 | 无 | **PA16 ADC** |
| 25E 旧拓展板叙述 | 天猛星脚 | **删除/不再使用** |

## 六、代码生成检查清单

1. 是否使用本拓展板？是 → 用本章总表，不必再猜电机脚  
2. motor_id 是否与 24H_4 一致（1=PA12 组，2=PA13 组）？  
3. 汇电籽-601 是否插在 UART3 座？协议见 `imu601.md`  
4. KEY1/2=PB6/PB7、旋钮 PA16、BEEP=PA15 低响、DEBUG=PA10/11？  
5. 灰度：H2 并口 或 **GanWei（DAT 主控悬浮输入）**？
